# Hospital Registry System

A comprehensive web-based hospital registry system built with HTML, CSS, and JavaScript. This project includes patient registration, advanced search and filtering, edit/delete functionality, and data analysis with interactive charts.

## Features

- **Patient Registration**: Add new patients with name, age, and condition
- **Advanced Search & Filtering**:
  - Search by name
  - Filter by age range
  - Filter by condition
- **Edit & Delete**: Modify or remove patient records
- **Data Analysis**: 
  - Age distribution bar chart
  - Condition distribution pie chart
- **Data Persistence**: Uses localStorage to save data between sessions

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Chart.js for data visualization

## How to Use

1. Open `index.html` in your browser to view the portfolio
2. Click "View Project" to access the hospital registry system
3. Register new patients using the form
4. Use filters to search and analyze patient data
5. Edit or delete patients as needed
